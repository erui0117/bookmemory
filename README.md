# 둘이 쌓는 책탑

둘이 함께 쓰는 독서 기록 사이트입니다. 다 읽은 책이 쪽수만큼의 두께로 쌓이고, 서로의 기록을 보고 한마디를 남길 수 있어요.

사이트 화면은 GitHub Pages가, 두 사람의 기록은 Firebase(무료 요금제)가 맡습니다. 아래 세 단계를 한 번만 하면 됩니다. 20분쯤 걸려요.

## 1. Firebase 만들기 (기록 저장소)

1. <https://console.firebase.google.com> 에 Google 계정으로 들어가 **프로젝트 추가**를 누릅니다. 이름은 아무거나, Google 애널리틱스는 꺼도 됩니다.
2. 왼쪽 메뉴 **빌드 > Firestore Database > 데이터베이스 만들기**. 위치는 `asia-northeast3 (서울)`, 모드는 **프로덕션 모드**.
3. Firestore의 **규칙** 탭을 열고, 내용을 전부 지운 뒤 이 폴더의 `firestore.rules` 내용을 붙여넣고 **게시**.
4. 왼쪽 메뉴 **빌드 > Authentication > 시작하기 > 로그인 방법**에서 **익명**을 켭니다.
5. 톱니바퀴 **프로젝트 설정 > 일반 > 내 앱**에서 웹 아이콘(`</>`)을 눌러 앱을 등록합니다. 호스팅 체크는 필요 없어요.
6. 화면에 나오는 `firebaseConfig = { ... }` 안의 값들을 `config.js`의 `firebase: { ... }` 자리에 붙여넣습니다.

이 값들은 비밀번호가 아니라 "어느 프로젝트인지" 알려 주는 주소 같은 것이라 공개 저장소에 올려도 괜찮습니다. 기록을 지키는 것은 3번의 규칙과 책탑 암호입니다.

## 2. GitHub에 올리기

1. GitHub에서 **New repository**. 이름은 예를 들어 `booktower`, 공개 범위는 **Public** (무료 요금제에서는 Public 저장소만 Pages를 쓸 수 있어요).
2. 저장소 화면에서 **Add file > Upload files**를 누르고, 이 폴더 안의 파일을 전부(`icons` 폴더 포함) 끌어다 놓은 뒤 **Commit changes**.
3. **Settings > Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 **Save**.
4. 1~2분 뒤 같은 화면에 주소가 나옵니다: `https://<내 아이디>.github.io/booktower/`

## 3. 둘이 쓰기 시작

1. 주소를 열면 **책탑 암호**를 묻습니다. 친구와 둘만 아는 긴 문장으로 정하세요 (8자 이상).
2. 친구에게 **주소와 암호**를 알려 줍니다. 친구가 같은 암호를 넣으면 같은 책탑이 보입니다.
3. 각자 이름과 색을 정하고 책을 기록합니다.
4. 홈 화면 추가
   - 아이폰·아이패드: Safari로 열기 → 공유 버튼 → **홈 화면에 추가**
   - 안드로이드: Chrome으로 열기 → ⋮ 메뉴 → **홈 화면에 추가** 또는 **앱 설치**
   - 홈 화면 아이콘으로 처음 열 때 암호를 한 번 더 넣어야 할 수 있어요.

## 책 검색 (선택: 알라딘 키)

키 없이도 Google Books로 검색됩니다. 다만 한국 책은 빠지거나 쪽수가 없는 경우가 있어요. 알라딘 키를 넣으면 한국 책 검색이 더 잘 됩니다.

1. 알라딘 OpenAPI 안내(<https://www.aladin.co.kr/ttb/apiguide.aspx>)를 따라 알라딘 계정으로 TTB 키를 발급받고, 사용할 주소로 내 GitHub Pages 주소를 등록합니다.
2. 받은 키를 `config.js`의 `aladinKey: ""` 따옴표 안에 넣고 GitHub에 다시 올립니다.

검색이 안 될 때는 언제든 제목과 쪽수를 직접 입력할 수 있습니다.

## "둘만" 쓴다는 것의 정확한 뜻

- 사이트 주소와 코드는 공개입니다. 주소를 아는 사람은 누구나 사이트를 열 수 있어요. 검색엔진에는 잡히지 않도록 표시해 두었습니다.
- **기록은 책탑 암호를 아는 사람만** 보고 고칠 수 있습니다. 암호는 어디에도 저장되지 않고, 암호에서 계산한 값이 기록 보관함의 이름으로 쓰입니다.
- 그래서 암호가 곧 열쇠입니다. 짧거나 뻔한 암호는 피하고, 암호를 바꾸고 싶으면 새 암호로 새 책탑을 시작하면 됩니다 (기록은 옮겨지지 않아요).

## 문제가 생기면

| 화면에 나오는 말 | 볼 곳 |
|---|---|
| 아직 설정 전이에요 | `config.js`에 firebaseConfig 값이 들어갔는지 |
| Firebase에 연결하지 못했어요 | 1단계의 4번(익명 로그인)이 켜졌는지, 인터넷 연결 |
| 기록을 읽거나 쓸 권한이 없어요 | 1단계의 3번 규칙을 그대로 붙여넣고 게시했는지 |
| 친구와 책탑이 다르게 보여요 | 암호의 띄어쓰기·대소문자까지 같은지 (이름 버튼 > 암호 다시 입력) |

## 파일 설명

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 전체 |
| `config.js` | Firebase 값과 알라딘 키. **고칠 파일은 이것뿐** |
| `firestore.rules` | Firebase 콘솔에 붙여넣을 접근 규칙 |
| `manifest.webmanifest`, `icons/`, `sw.js` | 홈 화면 아이콘과 앱처럼 열리게 하는 설정 |
